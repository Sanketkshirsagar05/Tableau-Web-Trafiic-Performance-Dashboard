# 📊 Web Traffic Performance Dashboard (Tableau)

An interactive **Web Traffic Analysis Dashboard** built using Tableau to monitor, analyze, and visualize website performance metrics. This project helps stakeholders understand user behavior, traffic sources, and engagement trends for better decision-making.

---

## 📌 Project Overview

This dashboard provides a **comprehensive view of web traffic performance**, including key KPIs, user engagement metrics, and traffic source analysis.

It is designed with a **clean, business-focused layout** to enable quick insights and data-driven decisions.

---

## 🎯 Key Features

- 📊 **KPI Monitoring**
  - Total Sessions
  - Session Duration
  - Avg Unique Pageviews
  - Avg Time on Page  
  - Month-over-Month comparison

- 🌍 **Traffic Source Analysis**
  - Top referral websites
  - Geographic traffic distribution (Map view)

- 💻 **Device Performance**
  - Desktop, Mobile, Tablet analysis
  - Bounce rate comparison

- 📈 **Channel Performance**
  - Paid Search, Organic Search, Direct, Referral, Social

- 📄 **Page-Level Insights**
  - Top performing pages
  - Engagement metrics & bounce rate

- 📅 **Trend Analysis**
  - Last 12 months performance tracking
